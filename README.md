## 图片滑动浏览

- 大图模式下向左滑动下一张，向右滑动上一张，首尾循环；支持触摸与鼠标拖动。
- 轻拖距离不足时回弹，快速轻甩可翻页；纵向手势不切图，长图保留上下滚动。放大后暂停切图，可自由滑动查看图片，缩小后恢复。
- 双指手势取消切图识别；上一张/下一张按钮和键盘方向键继续可用。

## 跟手与平滑切图

- 三个相邻图片面板同步跟随拖动，松手按距离/速度决定翻页或回弹；按钮和键盘切图也采用相同过渡。
- 提前加载并解码前后图片，过渡结束直接复用已到位的图片节点，避免重新换 src 导致闪图。
- 支持重抓正在移动的图片；短距离松手回弹、双指或纵向手势取消翻页；减少动态效果偏好下省略动画。
- 每张长图保留独立的纵向滚动区，放大与手机背景锁定机制继续保留。
