# 住前笔记

一个用于查阅装修攻略、整理预算与设计需求的图文笔记站。

## 功能

- 按装修阶段、内容类型和是否有配图筛选笔记，支持关键词搜索。
- 按推荐顺序或发布时间浏览，收藏需要反复查阅的笔记。
- 阅读分主题的图文内容、预算明细和对照表，通过目录快速跳转。
- 查看原帖配图，支持放大、左右滑动切图和长图上下阅读。
- 查阅作者、原帖链接和资料核对范围，区分原帖整理、本站建议与核算。
- 按八步规划逐项核对 40 项前期准备，查看阶段进度、完成标志与对应教程；保留 15 项补充检查及历史勾选。
- 在“我的家”中查看 3D 布置，切换鸟瞰、俯视与第一人称，联动阅读房间说明。
- 通过“查看设置”比较风格、方案和门状态；切换工作区保留筛选与模型状态。

## 使用方式

本项目为静态网站，无需安装前端依赖。准备 Git 和 Python 3 后运行：

```bash
git clone https://github.com/zycode1561/saya-renovation-notebook.git
cd saya-renovation-notebook
python3 -m http.server 5173 --directory dist --bind 127.0.0.1
```

在浏览器打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)。

选择装修阶段或输入关键词，点击卡片阅读笔记；点击配图查看大图，点击书签收藏。进入“检查清单”可逐项勾选确认。

收藏和清单进度保存在当前浏览器中，不跨设备同步。清除浏览器站点数据会清除这些记录。

如需自行托管，将 `dist/` 目录作为静态网站根目录部署即可。
