# 住前笔记

沙耶的装修攻略与避坑查阅站。无构建依赖，静态文件位于 `dist/`。

## 本地预览

在本目录运行 `python3 -m http.server 5173 --directory dist --bind 127.0.0.1`。

## 内容与状态

- `dist/data.js`：装修阶段与经过核对的来源笔记。只使用原创摘要、来源链接及核对范围，不托管原帖图片。
- `dist/app.js`：关键词检索、阶段/类型筛选、收藏、来源详情和检查清单。
- 收藏与清单通过当前浏览器 localStorage 保存，不跨设备同步。
- 首次发布资料核对日期：2026-10-22。链接由检索结果取得；小红书可能要求登录，访问令牌也可能失效，可按标题与作者在小红书查找。
- 页面外部字体有系统字体降级，不影响功能。
- `.openai/hosting.json`：Sites 站点配置；发布保持私人访问范围。
