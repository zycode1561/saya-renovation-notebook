## 2026-10-27：原生融入住前笔记

本目录是当前模型的权威维护源。根目录 `.code/home-design/` 保留迁入前的历史副本，后续请只修改本站点内的这份源码。

## 历史版本：成人视角第一人称漫游

在原离线方案页中加入“进入第一人称”和视图栏入口。WASD / 方向键按面朝方向前进、后退与平移；拖动转头，Q / E 转向，Esc 退出。手机可按住屏幕方向键移动，同时拖动画面转头。支持玄关、客厅、主卧、厨房、书房、次卧、主卫、阳台 8 个起点。

默认眼高 1.65 m，可调 1.45–1.85 m；眼高指眼睛距模型完成地面高度，不是身高。水平视场角默认 75°，可调 50–110°；按屏幕宽高比换算透视相机的垂直角，保持横竖屏的水平视场一致。视场角越大越广，并不代表空间变大。

漫游恢复原墙完整高度，在模型暂定的 2.7 m 高度补充仅漫游可见的顶面；不飞行、不抬升地面、不添加摇晃。以半径 22 cm 的圆形身体包络配合可见物体的网格包围盒，阻挡墙体、隔断、玻璃和家具，并限制在原地板范围内。碰撞为概念模型的近似，装饰曲线与地面细线不参与。门洞保留通行；窄角可沿障碍滑动，分段移动防止越过薄墙。漫游期间固定墙高，暂停家具与隔断切换；退出恢复原相机、墙高和动线状态。风格及日夜切换保留位置、眼高和视场角。所有素材继续内嵌，未发布到云端站点。
